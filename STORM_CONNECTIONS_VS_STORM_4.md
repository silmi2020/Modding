# STORM CONNECTIONS (`NSUNSC`) VS STORM 4 (`NSUNS4`) COMPATIBILITY MATRIX (`NSC-MOVESET-RESEARCH-001`)

Berdasarkan bukti langsung dari [NSC-Toolbox Repository](https://github.com/TheLeonX/NSC-Toolbox), [NSC-Toolbox Releases](https://github.com/TheLeonX/NSC-Toolbox/releases), [NSC-ModManager Releases](https://github.com/TheLeonX/NSC-ModManager/releases), dan seri video [Medrej Storm™](https://www.youtube.com/watch?v=TKH_TtuOhNI):

| Elemen / Mekanisme | *Naruto x Boruto: Ultimate Ninja Storm Connections* (`NSUNSC` v1.60/v1.70) | *Naruto Shippuden: Ultimate Ninja Storm 4* (`NSUNS4` v1.09) | Tingkat Kompatibilitas | Bukti & Catatan Implementasi |
| :--- | :--- | :--- | :--- | :--- |
| **Struktur Container `prm.bin.xfbin` (`_bas`, `_mot`, `_atk`, `_spl`) & `prm_load.bin.xfbin`** | Menggunakan format container `NUCC` (`XFBIN`) di `data_win32/spc/` dan `data_win32/spcload/`. | Menggunakan struktur `spc/xxxprm.bin.xfbin` dan `spcload/xxxprm_load.bin.xfbin` yang sama; diedit menggunakan tool `Character Moveset Editor` dan `Character File Loader Editor` yang sama di `NSC Toolbox`. | **`Verified compatible`** (`[VERIFIED IN SOURCE]`) | [README NSC-Toolbox](https://github.com/TheLeonX/NSC-Toolbox): *"Storm 4 toolbox and Storm Connections toolbox got merged together... Tools which didn't changed color works for both games."* |
| **Mekanisme Rantai `PL_ANM_ATK`, `PL_ANM_ATK_AIR`, dan `PL_ANM_THROW_*`** | Dikendalikan oleh `PL_ANM Section Name`, `Previous PL_ANM`, `Combo Direction`, `Trigger Condition 1`, dan `Function List` (`ME_`). | Menggunakan skema state machine `PL_ANM` yang identik. Bahkan file `prm.bin.xfbin` dari *Storm Generations* dapat dibuka langsung dan disalin ke `NSUNSC` (`YKgLFsMCpm0` `02:30`). | **`Verified compatible`** (`[VERIFIED IN VIDEO]` & `[VERIFIED IN SOURCE]`) | Penyambungan node `ATK`, `ATK_AIR`, dan `THROW` dapat ditransfer langsung antara `NSUNSC` dan `NSUNS4`. |
| **Teknik Retargeting Lintas Karakter via HxD (`[char]00t0` $\rightarrow$ `1cmnbod1`/`1cmn00t0` + `Enable Outlaw Max`)** | Terbukti bekerja pada [Video 4 — Changing Grab](https://www.youtube.com/watch?v=K_DrvEl2XBE) (`00:42–04:32`). | Kerangka umum `1cmnbod1` / `1cmn00t0` dan flag `Enable Outlaw Max` (*Cube Man*) berasal dari arsitektur engine *Storm* generasi sebelumnya (termasuk *Storm 4*). | **`Conceptually transferable`** (`[STRONG INFERENCE]`) | Prosedur HxD `1cmnbod1`/`1cmn00t0` relevan untuk *Storm 4*, namun wajib diuji per karakter karena perbedaan jumlah kemunculan string `[char]00t0`. |
| **Sistem Kontrol *Side Combo* (`Combo Direction = 3`), *Tilt*, dan *Chakra Shuriken*** | Vanilla `NSUNSC` menghapus *Side Combo*, *Tilt*, dan *Chakra Shuriken* demi skema kontrol Jutsu ke-2. Namun enum `3 = Side` masih aktif di engine (`YKgLFsMCpm0`), dan `UltimateStormAPI v2.0.0.0+` merestorasi *Tilt* serta *Chakra Shuriken*. | Vanilla `NSUNS4` masih memiliki *Tilt* dan *Chakra Shuriken* bawaan, serta mendukung `Combo Direction = 3 = Side`. | **`Requires adaptation`** (`[VERIFIED IN VIDEO]` & `[VERIFIED IN SOURCE]`) | Di `NSUNS4`, *Chakra Shuriken* dan *Tilt* sudah aktif tanpa patch kontrol, tetapi fitur baru seperti *Shuriken Tilt* (`PL_ANM_ATK_FAR00_ANOTHER`) memerlukan `UltimateStormAPI v2.0.1.0+`. |
| **Porting Langsung File `prm.bin.xfbin` dari `NSUNSC` ke `NSUNS4`** | Menggunakan beberapa `Damage Code` baru (seperti reaksi *Down Slow* dan `DAMAGE_ID_DOWN` versi NSC). | Menyalin `prm.bin.xfbin` mentah dari `NSUNSC` ke `NSUNS4` menyebabkan bug damage/reaksi jika tidak memakai `UltimateStormAPI v2.0.1.0+`. | **`Requires adaptation`** (`[VERIFIED IN SOURCE]`) | [NSC-ModManager Releases v2.0.1.0](https://github.com/TheLeonX/NSC-ModManager/releases): *"Storm 4: Fixed issue when DAMAGE_ID_DOWN action from NSC didn't worked correctly in Storm 4. Fixed issue when 5ssk's Down Finisher didn't do damage if prm file was taken from NSC."* |
| **Jumlah Slot Jutsu di `prm_load.bin.xfbin` (`Jutsu 1..6`)** | Mendukung hingga 6 slot Jutsu (`Jutsu 1` s.d. `Jutsu 6`) dan *Jutsu Selector* melalui `UltimateStormAPI`. | Hanya menggunakan slot Jutsu standar kecuali diperluas oleh `UltimateStormAPI` (yang memisahkan folder `param/NS4/` dan `param/NSC/`). | **`Requires adaptation`** (`[VERIFIED IN SOURCE]`) | Lihat tooltip Kyuruto di `XMqRwv2715s` (`00:36`): *"This tool is required for changing default jutsus of character (you can load all 6 jutsus, but pick only 2 for your character)."* |
| **File Fisika Aksesori (`bod1acc.bin.xfbin`) dan Format Audio (`NUS3BANK` / SFX)** | Menggunakan struktur `bod1acc` dan format audio khusus `NSUNSC`. | Menggunakan format audio dan `bod1acc.bin.xfbin` khusus `NSUNS4`. | **`Incompatible`** (tanpa konversi manual) (`[VERIFIED IN SOURCE]`) | [NSC-ModManager Releases v2.0.0.0](https://github.com/TheLeonX/NSC-ModManager/releases): *"Mods work in both games, but Naruto Storm 4 and Naruto Storm Connections require some different files... Mostly just sounds and 'bod1acc.bin.xfbin' files."* |
