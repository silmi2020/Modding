# MOVESET TROUBLESHOOTING & ROOT-CAUSE ANALYSIS PLAYBOOK (`NSC-MOVESET-RESEARCH-001`)

Panduan diagnosis terstruktur (`Gejala` $\rightarrow$ `Kemungkinan Akar Masalah` $\rightarrow$ `Bukti yang Diperiksa` $\rightarrow$ `Pengujian Pembeda` $\rightarrow$ `Perbaikan & Validasi`) untuk kelima kategori modifikasi moveset:

| Gejala Kegagalan | Kemungkinan Akar Masalah (Root Cause) | Bukti yang Perlu Diperiksa | Pengujian Pembeda (Diagnostic Test) | Perbaikan & Validasi (Dengan Backup) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Modifikasi tidak terlihat sama sekali di dalam game (masih gerakan lama)** | (a) Lupa mengklik tombol `Save` pada sub-panel (`Function` / `Projectile List`) atau `Save PL_ANM Settings` sebelum `File -> Save`; atau (b) Menjalankan `Compile Mods And Launch Game` di [NSC Mod Manager](https://github.com/TheLeonX/NSC-ModManager) yang otomatis menghapus folder `data_win32`. | Buka ulang file di `data_win32/spc/xxxprm.bin.xfbin` dengan `NSC Toolbox` untuk memeriksa apakah nilai baru masih tersimpan. | Periksa keberadaan file di `data_win32/spc/` setelah game berjalan. | Selalu tekan `Save` berjenjang (Sub-panel $\rightarrow$ `Save PL_ANM Settings` $\rightarrow$ `File -> Save`), dan gunakan **`Export Mod`** di `NSC Toolbox` jika memakai `NSC Mod Manager`. |
| **2. Aksi baru (Side Combo / Air Combo / Grab) tidak dapat dipicu dari input kontrol** | (a) `Previous PL_ANM` tidak cocok dengan section pendahulunya (misal pada Side Combo `1ssk`, `ATK07` harus menunjuk ke `PL_ANM_ATK04`, bukan `ATK02`); (b) `Combo Direction` salah; atau (c) `Trigger Condition 1` bernilai `16` (*hit giant*). | Periksa `Previous PL_ANM`, `Combo Direction`, dan `Trigger Condition 1` pada node awal cabang di `Character Moveset Editor`. | Ubah sementara `Combo Direction` menjadi `0 = All Directions` dan `Previous PL_ANM` menjadi `PL_ANM_ANY` (sebagai `ATK00`) untuk menguji apakah node tersebut valid. | Sesuaikan `Previous PL_ANM` dengan nama persis node pukulan sebelumnya, setel `Combo Direction` (`3 = Side`, `1 = Up`, `2 = Down`), dan pastikan `Trigger Condition 1 = 0`. |
| **3. Karakter membeku (freeze), T-pose, atau melompati animasi saat mengeksekusi Grab / Combo lintas karakter** | (a) Container `bod1` tambahan belum didaftarkan di `spcload/xxxprm_load.bin.xfbin`; (b) Untuk lintas karakter (seperti Video 4), string `[char]00t0` di dalam `bod1` belum diubah menjadi `1cmnbod1` (ke-1) & `1cmn00t0` (sisanya) di HxD; atau (c) Checkbox **`Enable Outlaw Max`** belum dicentang. | Periksa `xxxprm_load.bin.xfbin` (`Type: 3 - bod1`, `Load Condition: Base`), periksa hex `bod1` di HxD, dan cek status `Enable Outlaw Max` di `Moveset Editor`. | Ganti sementara field `Animation` ke nama animasi asli karakter penerima. Jika berjalan lancar, masalah 100% pada ikatan `bod1` / `1cmn00t0`. | Jalankan script `argon_moveset_toolkit.py retarget-bod1` (atau HxD), daftarkan di `prm_load`, dan centang `Enable Outlaw Max` (untuk `1cmnbod1`) atau pilih indeks `3 = bod1` kedua pada `File Type` (untuk karakter yang sama). |
| **4. Wajah karakter terdistorsi / rusak parah saat menjalankan animasi Grab atau Combo milik karakter lain** | Checkbox **`Enable Face Animations`** masih dicentang pada section `PL_ANM` yang memakai animasi karakter lain (`1cmnbod1`). | Periksa kotak centang `Enable Face Animations` di sudut kanan atas tab `Moveset Settings` (`K_DrvEl2XBE` `04:04–04:13`). | Hapus centang `Enable Face Animations` pada salah satu section (`PL_ANM_THROW_BEGIN`) dan amati perubahan mesh wajah di dalam game. | Hapus centang **`[ ] Enable Face Animations`** pada seluruh section `PL_ANM` yang menggunakan animasi retargeting lintas karakter, lalu simpan. |
| **5. Shuriken baru atau efek batu/ledakan pada Grab/Ultimate Jutsu tidak muncul (invisible projectile/VFX)** | (a) File `skill/xxx.xfbin` (`Type: 11 - skill`) dan/atau `spc/xxxeff1.xfbin` (`Type: 10 - eff1`) belum ditambahkan ke `xxxprm_load.bin.xfbin`; atau (b) `ME_ENTRY_COMBO_SKILL_N_COORD` memanggil nama `String Param` (`COMBO11`/`COMBO12`) yang belum ada di tab `Projectile List`. | Periksa kecocokan antara `String Param` di `Function List`, nama entri di `Projectile List`, dan daftar file di `Character File Loader Editor`. | Pada kasus Shuriken saat Awakening (`XMqRwv2715s` `02:55`), periksa apakah `AWA_SYURIKEN` juga sudah diubah selain `SYURIKEN`. | Daftarkan kedua file (`Type 11 - skill` dan `Type 10 - eff1`) di `prm_load.bin.xfbin`, dan pastikan `Projectile List` memiliki entri `SYURIKEN`, `AWA_SYURIKEN`, atau `COMBO11`/`12` dengan `Skill File Name` & `Skill Entry Name` yang valid. |
| **6. Game mengalami crash saat memuat pertarungan setelah mengedit `bod1` di HxD** | Penggantian string di HxD mengubah panjang byte file (misal mengganti string 8 byte dengan string 7 atau 9 byte, atau menggunakan mode *Insert* alih-alih *Overwrite*), sehingga merusak seluruh tabel offset chunk `NUCC` (`XFBIN`). | Bandingkan ukuran byte (`file_size_bytes`) file `bod1.xfbin` sebelum dan sesudah diedit menggunakan `argon_moveset_toolkit.py`. | Kembalikan file `bod1` dari `.bak`; jika crash hilang, maka file `bod1` mengalami korupsi offset biner. | Gunakan fitur `retarget-bod1` pada `argon_moveset_toolkit.py` yang memvalidasi kesamaan panjang string tepat 8 byte (`[char]00t0` $\leftrightarrow$ `1cmnbod1` / `1cmn00t0`) dan memastikan ukuran file tetap identik 100%. |
